# Desarrollo

Usa Python 3.10 o posterior. Ejecuta `python -m unittest discover -s tests -v`
y `python -m app demo` antes de proponer un cambio. Añade pruebas de regresión
para reglas de negocio, permisos y transiciones; describe el caso que corrigen.

Los ejemplos de `data/` contienen datos sintéticos. No añadas exportaciones
de clientes, bases SQLite ni archivos `.env`. Mantén las decisiones de diseño
en `docs/decisions.md` y explica cualquier cambio de contrato.
